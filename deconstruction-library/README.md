# Optional research workspace

`deconstruction-library/` is an optional research workspace for notes, deconstructions, benchmarks, and writing-method source material that the author may keep beside the project.

It is **not read by novel-core**, is not indexed or synchronized by Core, and is **never authoritative** for project state or Canon. Content here only affects a book when the author or ChatGPT deliberately reads it and converts useful ideas into the current workspace protocol artifacts.

The directory is ignored by Git except for this README so private or copyrighted research material is not committed accidentally.
