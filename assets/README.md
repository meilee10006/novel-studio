# Optional writing references

This directory contains optional writing references and style notes for human/ChatGPT use.

- `references/` contains craft notes, templates, planning heuristics, and prose guidance.
- `styles/` contains optional style notes.

These files are **not loaded by novel-core**. They are not part of the Core protocol, do not affect validation, and are **never authoritative** for project state or Canon. A user or ChatGPT conversation may consult them deliberately, but accepting or changing Canon always goes through the generated workspace protocol and `novel-core`.

Provider credentials, model routing, Agent prompts, RAG/Qdrant instructions, and old pipeline runtime documentation are intentionally not kept here.
